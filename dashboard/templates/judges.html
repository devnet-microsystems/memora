Memora — Technical Overview for Judges

1. 60-Second Overview

What is Memora? A private AI assistant acting as a second brain.
For whom? People with Mild Cognitive Impairment (MCI) and their caregivers.
"The user forgets. The system doesn't."

2. Try it in 60 seconds

1
Open the Patient App and say (or type): "Where is the nearest pharmacy?". Memora will route this to Tavily search seamlessly.
Open Patient App
2
Ask 3 times: "Did I take my pill?". Memora detects the repetition and logs confusion.
3
Open the Caregiver Dashboard to see the newly generated Alert and the updated Memory Graph.
Open Caregiver Dashboard

3. What is Real vs Simulated

Component Status Details
LLMs & Orchestration REAL Using Nebius Token Factory (Nano, Super, Ultra, Qwen embeddings). Real multi-model routing based on intent.
Web Search REAL Tavily API used for real-time external world queries.
Memory Graph DB REAL Local SQLite encrypted with SQLCipher. Real RAG over the graph.
Patient History SIMULATED "Maria" is a simulated persona. 7 days of past interaction logs are seeded on boot to populate the caregiver graphs.
Medical Data SIMULATED No real clinical data. Memora is strictly not a medical device.
