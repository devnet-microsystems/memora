🧠 Memora

The user forgets. The system doesn't.

Memora is an AI companion that supports people with cognitive impairment by remembering facts, tracking habits, and alerting caregivers when needed.

🎙️ Patient App 📊 Caregiver 🏆 Judges

How it works

💬 Talks

A simple, zero-friction voice interface tailored for accessibility and cognitive comfort.

🧠 Remembers

Builds a persistent memory graph extracting facts, habits, and preferences in real time.

🆘 Alerts

Notifies caregivers of missed medications, confusion, or explicit distress signals instantly.
